The Solution

RS232 as the Bridge

Industrial scales almost always have an RS232 port. They output weight data automatically after each measurement. That is the entry point.

Core Insight
Instead of replacing working hardware that cost tens of millions, a sub-Rp 150,000 ESP32 + RS232-to-TTL module sits alongside each scale. It reads the serial output, parses the weight string, and POSTs the batch to Supabase over Wi-Fi. The scales are never touched — no firmware update, no hardware modification, no downtime.
RS232 Parsing
Char-by-char Buffer, Triggered by =
The Sonic A15E (XK3190-A15E) outputs a serial string where the = character signals the weight reading. The ESP32 firmware reads UART byte by byte, buffering until it sees =, then parses the number that follows. No standard format exists across manufacturers — a Digi DS-560 or Jadever JWI-3000 would use different delimiters (CR/LF, prefix ST,GS,, etc.), requiring a different parser per model.
RS232 Parser · Sonic A15E (XK3190-A15E)

Known Limitation
No POST retry If the ESP32 loses Wi-Fi between a weighing event and the POST, that batch is lost — no local buffer or retry queue. A gap in the dashboard timeline signals connectivity loss. In practice (indoor factory, stable Wi-Fi), this has not been an issue.

02
Z-Score Anomaly Detection
Every batch evaluated against the historical mean and standard deviation for that material — accumulated from all prior batches for that same material. No manual threshold configuration: the more data, the more stable the baseline. A flour batch that normally arrives at 25 kg but arrives at 2 kg or 80 kg is flagged immediately. Early batches (fewer than ~5 per material) produce wider variance and may miss subtle anomalies — detection sharpens as data accumulates.

The Broader Point

The Pragmatic Pattern

RS232 · Modbus RTU · Legacy Serial
RS232, Modbus RTU, and legacy serial protocols are still everywhere in Indonesian manufacturing. Machines that work perfectly and cost tens of millions sit disconnected from any digital system — not because connectivity is impossible, but because no one has built the bridge. The same ESP32 pattern applies to any machine with a serial output port: scales, ovens, mixers, conveyors. The hardware cost of connectivity is now under Rp 200,000 per machine. The barrier is knowing how.
